# Cosmic Portfolio Dreams

Create a fully 3D animated portfolio website for Kamal Solanki based on the GitHub repository https://github.com/kamalsolanki143/KAMAL-SOLANKI-portfolio and inspired by the attached video style.

Visual design and 3D animations:
- Dreamy purple, deep violet, and midnight dark aesthetic with ambient luminous neon glows
- Interactive 3D scene (Three.js / React Three Fiber) with floating geometric shapes, glowing particles, and responsive mouse parallax
- Glassmorphism frosted glass cards with 3D tilt effects, smooth lighting shifts, and fluid entrance animations
- Sections:
  1. Hero section with interactive 3D animation, glowing title "KAMAL SOLANKI", subtitle highlighting Data Science, IIT Madras Statistics & Full-Stack Development, and quick action buttons
  2. About Me card with smooth expand/tabs and interactive badges
  3. Featured Projects with 3D hover effects, live demo and GitHub repository links
  4. Skills Matrix & Technologies with categorized visual chips and animation
  5. Academic Journey & Achievements (IIT Madras Data Science & Statistics)
  6. Interactive Contact section with floating social links and message form
- Fully responsive across mobile, tablet, and desktop with smooth scroll navigation
