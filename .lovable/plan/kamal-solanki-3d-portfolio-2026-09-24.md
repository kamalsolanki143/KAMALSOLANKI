# Kamal Solanki 3D Portfolio

## Build
- Replace the blank home page with a single immersive portfolio experience inspired by the supplied cinematic violet reference.
- Add a full-viewport interactive Three.js scene with a luminous data core, orbiting geometry, particles, pointer parallax, and reduced-motion support.
- Add sticky smooth-scroll navigation and responsive sections for Hero, About, Projects, Skills, Academic Journey, and Contact.
- Use verified content and public links from Kamal’s GitHub portfolio repository.
- Add frosted glass panels, perspective tilt, animated entrances, interactive tabs/chips, and working contact actions.

## Visual direction
- Midnight black and deep violet base, lavender highlights, restrained warm sunset accents, luminous depth, and atmospheric grid details.
- Bold geometric display typography with compact technical labels.
- Mobile layouts retain the 3D scene while simplifying density and motion.

## Technical details
- Install Three.js, React Three Fiber, Drei, and Motion.
- Keep browser-only 3D code isolated behind client-only loading for safe page rendering.
- Define all visual colors and shadows as semantic tokens in the global stylesheet.
- Add complete page metadata and verify the rendered experience at desktop and mobile sizes.
