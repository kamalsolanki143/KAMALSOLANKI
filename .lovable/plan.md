# Portfolio Polish — Richer Look, Deeper Animation

## Goal
Website ko aur premium, alive aur cinematic banana — reference video jaisi depth ke saath zyada motion, glow aur interactivity.

## What improves

### 1. Hero (first screen)
- "KAMAL SOLANKI" title letter-by-letter reveal + subtle glowing shimmer sweep.
- Animated gradient glow behind the title (pink/violet light bloom that slowly breathes).
- Portrait parallax: chips aur photo mouse ke saath halki 3D tilt karein.
- Bottom mein animated "scroll" indicator (ghoomti hui line / bounce arrow).

### 2. 3D world background
- Floating glowing orbs / fireflies (Ghibli jaisi tairti roshni) — color scroll ke saath badle (section ke theme ke hisaab se).
- Subtle animated gradient aur film-grain overlay for cinematic texture.
- Section change par light color smoothly shift ho.

### 3. Scene transitions
- Har frame viewport mein aate hue 3D tilt + depth blur se clear hota ho.
- Content ke elements stagger hokar andar aayein (label → heading → copy → cards).

### 4. Cards & interactions
- Project aur recognition cards par 3D hover tilt + glow border.
- Skills chips cascade animation jab section dikhe.
- Buttons par magnetic hover effect (cursor ki taraf halka khinchein).

### 5. Contact & footer
- Copy-email button par confetti-spark feedback.
- Social links floating bob animation.

### 6. Mobile + performance
- Mobile par reduced orb count, same look-lite.
- reduced-motion respect rahe.

## Verification
- Desktop (1280px) aur mobile (390px) Playwright screenshots har chapter ke.
- Build clean, no console errors.
